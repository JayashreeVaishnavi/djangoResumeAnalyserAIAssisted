# Product: ResumeLens (local-only)

ResumeLens analyses a resume against a job description (JD) and produces:
- a hybrid match score (0-100) with requirement-by-requirement evidence
- ATS keyword/format findings
- tailored bullet rewrites that I can accept or reject

It runs ONLY on my laptop for my personal use. It is never hosted.
No auth, no multi-user, no cloud calls, no telemetry. Resume data never leaves the machine.

Portfolio goal: demonstrate Django, LLM engineering and agentic AI in one project,
so code quality, tests and a visible agent trace matter more than extra features.
