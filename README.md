# ResumeLens: Kiro starter

1. Install Ollama (https://ollama.com), then:
   ollama pull llama3.1:8b
   ollama pull nomic-embed-text
   (8 GB RAM? use `llama3.2:3b` and set LLM_MODEL accordingly)
2. Install Kiro (https://kiro.dev) and sign in.
3. Copy this folder somewhere, `cd` into it, run `python -m venv .venv` and activate it, then `kiro .`
4. In Kiro: open the Kiro panel (ghost icon) -> Specs -> `resumelens` -> open tasks.md -> Start task 1, then continue in order.
